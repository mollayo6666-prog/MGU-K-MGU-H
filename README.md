# F1 MGU-K · MGU-H Energy Simulator

고등학교 과학 발표를 위한 Formula 1 하이브리드 에너지 회수 시뮬레이터입니다.

## 주요 기능

- 바쿠 2번 코너의 제동·가속 에너지 흐름 애니메이션
- 2025 규정: MGU-K 최대 120 kW와 MGU-H
- 2026 규정: MGU-H 삭제와 MGU-K 최대 350 kW
- 화면 클릭 또는 Space 키로 재생·일시정지
- 2025 Kick Sauber 및 2026 Audi 스타일 차량

## 사이트

<https://mollayo6666-prog.github.io/MGU-K-MGU-H/>

`main` 브랜치에 푸시하면 GitHub Actions가 사이트를 자동으로 다시 배포합니다.

## 로컬 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
```
